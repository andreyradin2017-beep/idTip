# idTip

Небольшой аддон для **WoW 3.3.5a / Sirus x3**: показывает ID предметов и заклинаний прямо в тултипах.

## Что умеет

- показывает `ID предмета` / `ItemID` у предметов;
- показывает `ID заклинания` / `SpellID` у баффов, дебаффов, аур и заклинаний;
- работает в обычном GameTooltip, ссылочных тултипах (`ItemRefTooltip`) и сравнительных тултипах;
- цвет числа ID белый, без «перетекания» цвета дальше;
- на русском клиенте подписи на русском (`ID предмета`, `ID заклинания`);
- защита от дублирующихся строк при обновлении тултипа.

## Установка

1. Скопировать папку `idTip` в:

   ```
   World of Warcraft\Interface\AddOns\
   ```

2. Включить аддон в меню выбора персонажа.
3. Если игра уже запущена — выполнить `/reload`.

## Как использовать

Аддон работает автоматически. Просто наводите курсор на предметы, баффы, дебаффы, ауры и заклинания — ID появится внизу тултипа.

## Технические замечания

- Аддон использует `hooksecurefunc` и `HookScript`, поэтому не ломает защищённые Blizzard-функции.
- ID берётся из игрового API (`UnitBuff`, `UnitDebuff`, `UnitAura`, `GetSpell`, `GetItem`).
- Протестировано только статически; в игре стоит проверить баффы, дебаффы, ссылки из чата и сравнительные тултипы.

## Лицензия

Аддон основан на идее оригинального Silverwind idTip. Код можно свободно изменять и распространять.
